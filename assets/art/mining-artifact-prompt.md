# Mining Artifact Source Note

`mining-artifact.png` is a 256x256 nearest-neighbor export of a transparent
ImageGen source. It is deliberately an asymmetric obsidian relic rather than a
generic orb so it reads as a recoverable object at mining-grid scale.

Prompt: “Single transparent-background mining-game sprite: asymmetrical angular
obsidian relic core with three dark fins, luminous cyan crystalline heart, amber
circuit inlays, and restrained magenta signal fractures. Crisp 1990s arcade
pixel art, dark outline, limited palette, readable at 28px. True transparent
background only; no checkerboard, shadow, text, watermark, border, terrain, or
circle/orb silhouette.”

Authoring references: the friendly mining rig, Io tile sheet, and lava enemy
sheet in this directory. Runtime registration and atlas generation are in
`scene-textures.json`.
